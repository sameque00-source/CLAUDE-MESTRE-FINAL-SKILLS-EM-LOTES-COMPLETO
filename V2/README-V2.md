# CLAUDE-CODE-VS-AUTO-ULTIMATE-V2

Nova base arquitetural construída a partir da base original e das lições
observadas durante a evolução do Hunter/9Router.

Objetivo: uma base de agentes mais resiliente, verificável e organizada.

IMPORTANTE:
- nenhuma arquitetura de software pode garantir literalmente "zero erros para sempre";
- a meta desta V2 é detectar falhas, impedir encerramento prematuro, corrigir quando
  possível, falhar honestamente quando necessário e manter evidência.
- `SOURCE-ORIGINAL/` é somente referência/backup.
- `V2/` é a nova base limpa e organizada.
