# Multiagente V2

Composição dinâmica:

Research
Architect
Developer
QA
Security
Reviewer
etc.

Regras:
- selecionar somente especialistas necessários;
- tarefas independentes em paralelo;
- tarefas dependentes após conclusão;
- resultados em contrato estruturado;
- consolidador detecta divergência;
- veto pode bloquear conclusão;
- especialistas não recebem toda a memória;
- cada especialista recebe contexto mínimo necessário.
