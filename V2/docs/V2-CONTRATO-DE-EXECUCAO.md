# Contrato de Execução V2

Toda missão deve possuir:

MISSION_ID
OBJECTIVE
SCOPE
CONSTRAINTS
SUCCESS_CRITERIA
BUDGET
RISKS

Toda tarefa deve possuir:

TASK_ID
TYPE
INPUT
CONTEXT
DEPENDENCIES
AGENT
TOOLS
MODEL
SUCCESS_CRITERIA
RETRY_POLICY

Todo resultado deve possuir:

STATUS
EVIDENCE
ARTIFACTS
TESTS
ERRORS
CORRECTIONS
TRACE
NEXT_ACTION

Estados válidos de tarefa:
PLANNED
READY
RUNNING
VERIFYING
FAILED_RECOVERABLE
RETRYING
BLOCKED
SUCCEEDED
FAILED_HONEST

Nunca usar sucesso implícito.
