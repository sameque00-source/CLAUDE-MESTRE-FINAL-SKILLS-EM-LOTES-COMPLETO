# APIs, Data, and Integrations

## API contract
Confirm URL, method, authentication, inputs, outputs, errors, rate limits, pagination, versioning, idempotency, retries, and compatibility.

## Webhooks
Verify signatures where provided, make handlers idempotent, persist event identity when needed, bound retries, and expose operational diagnostics without leaking secrets.

## Databases
Inspect schema, relationships, constraints, indexes, transaction boundaries, migrations, seeds, and backup/rollback requirements. Never run destructive migrations merely because a task mentions the database.

## Data quality
Detect duplicates, stale state, impossible combinations, referential mismatches, and partial writes.
