# Testing and Release

## Test pyramid
Use focused unit tests for pure logic, integration tests for boundaries, and E2E tests for critical user journeys.

## Quality gates
Require objective evidence for build, lint/static checks, tests, security checks, and critical browser flows.

## Release
Prepare artifact/version, environment checks, migration readiness, smoke tests, observability, and rollback.

## Verification
After release, run a small set of production smoke checks appropriate to the system. Record exact results and blockers.
