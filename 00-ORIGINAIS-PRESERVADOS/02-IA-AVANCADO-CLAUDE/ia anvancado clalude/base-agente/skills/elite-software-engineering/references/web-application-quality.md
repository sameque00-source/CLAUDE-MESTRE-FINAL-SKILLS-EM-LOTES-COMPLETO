# Web Application Quality

## Visual quality
Evaluate rendered pages, not only source. Check hierarchy, spacing, typography, contrast, states, responsive composition, and consistency.

## Accessibility
Verify semantics, labels, keyboard navigation, focus, contrast, touch targets, reduced motion, and assistive-technology-friendly names.

## Browser QA
Use real browser automation when available. Capture screenshots for important views. Inspect console errors, failed requests, broken assets, routes, forms, and critical flows.

## Performance
Optimize images, fonts, scripts, network, rendering, and interaction. Measure before changing a reported bottleneck.

## SEO
Use meaningful titles/descriptions, canonical URLs, semantic headings, structured data where valid, indexability controls, and correct image alt text.
