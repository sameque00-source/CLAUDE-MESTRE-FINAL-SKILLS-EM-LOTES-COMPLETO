# Software Engineering Universe

## Purpose
This is a single-upload Skill package designed for Claude.ai. It consolidates the
source collection into a small number of domain reference files so the package
stays within common Skill upload limits while preserving the source guidance.

## Operating rules
1. Understand the user's objective, constraints, environment, and success criteria before acting.
2. Route each request to the smallest relevant domain reference file(s).
3. For cross-domain work, combine only the references that materially apply.
4. Treat reference material as guidance, not proof that a tool, API, deployment,
   test suite, browser, agent, or external system was actually executed.
5. Never invent credentials, secrets, tool results, benchmarks, agents, or verification.
6. For security, privacy, legal, compliance, financial, medical, or other high-stakes
   topics, distinguish general guidance from verified/current requirements.
7. For implementation work, inspect the provided project/materials first and preserve
   existing behavior unless a breaking change is explicitly requested.
8. Prefer the smallest safe change that satisfies the requirements.
9. Validate important claims and implementation results with concrete evidence when available.
10. Clearly separate completed work, verified results, assumptions, and remaining uncertainty.

## How to use the references
1. Identify the user's task and affected domain(s).
2. Open only the relevant domain reference file(s).
3. Within that file, use the matching source Skill section as the specialized methodology.
4. Do not treat a source Skill's description as evidence that its named tools or systems exist in the current environment.
5. Apply the user's explicit constraints before any generic recommendation.
