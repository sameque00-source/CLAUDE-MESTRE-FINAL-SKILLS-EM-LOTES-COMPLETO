# Ferramentas e MCP

Ferramentas são capacidades, não objetivos.

Política:
- cada agente possui conjunto de tools permitido;
- tools perigosas exigem guardas;
- tools desnecessárias não entram no contexto;
- MCPs são carregados sob demanda;
- erros de tool são observáveis;
- timeout e cancelamento são tratados;
- tool concluída não encerra missão.

Quando uma ferramenta não estiver disponível:
→ usar fallback compatível
→ ou declarar indisponibilidade.
Nunca inventar execução.
