# Gates de Qualidade V2

GATE 1 — Planejamento:
O plano cobre o objetivo e possui dependências válidas?

GATE 2 — Execução:
As ações foram realmente executadas?

GATE 3 — Artefatos:
Os arquivos/resultados realmente existem?

GATE 4 — Testes:
Os testes adequados foram executados e passaram?

GATE 5 — Security:
Não há secret, path traversal ou comando perigoso indevido?

GATE 6 — Reviewer:
A solução atende ao objetivo e não há lacunas conhecidas?

GATE 7 — Evidência:
Existe prova suficiente para afirmar sucesso?

Qualquer gate bloqueado:
→ missão NÃO pode ser declarada concluída.
