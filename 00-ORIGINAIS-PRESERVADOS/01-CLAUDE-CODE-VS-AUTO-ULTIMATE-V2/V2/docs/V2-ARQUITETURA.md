# V2 — Arquitetura

CAMADA 1 — Entrada
→ entender intenção, contexto e restrições.

CAMADA 2 — Planejamento
→ decompor objetivo, criar DAG, identificar riscos, definir critérios de sucesso.

CAMADA 3 — Orquestração
→ coordenar tarefas, dependências, locks e paralelismo.

CAMADA 4 — Roteamento
→ escolher agente, modelo, provider e ferramentas segundo capacidade real.

CAMADA 5 — Especialistas
→ carregar somente as personas/skills necessárias.

CAMADA 6 — Execução
→ ferramentas reais em workspace isolado.

CAMADA 7 — Verificação
→ testes objetivos, QA, Security e Reviewer.

CAMADA 8 — Recuperação
→ diagnosticar, corrigir, mudar estratégia, replanejar ou falhar honestamente.

CAMADA 9 — Memória
→ armazenar decisões, conhecimento, erros e soluções úteis.

CAMADA 10 — Evidência
→ produzir trace, logs e artefatos verificáveis.

REGRA:
Nenhuma etapa pode declarar SUCESSO somente por produzir texto.
SUCESSO requer evidência compatível com a tarefa.
