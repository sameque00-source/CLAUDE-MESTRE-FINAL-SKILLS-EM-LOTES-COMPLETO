# Relação com o Hunter

O Hunter já construiu capacidades reais que devem servir de referência:

- orquestração;
- planejamento;
- execução;
- especialistas;
- pesquisa;
- memória;
- roteamento;
- autocorreção;
- multimídia;
- projetos persistentes.

A V2 deve absorver as lições dessas implementações, mas não deve copiar
cegamente bugs, históricos ou arquivos de teste.

O objetivo é uma base limpa e reutilizável para o Hunter.
