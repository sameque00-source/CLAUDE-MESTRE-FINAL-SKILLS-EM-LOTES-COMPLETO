# Matriz de Testes V2

A V2 deve testar pelo menos:

1. missão simples
2. missão complexa
3. primeiro tool call seguido de continuação
4. paralelismo
5. dependências
6. ciclo no DAG
7. tool failure
8. model failure
9. provider failure
10. quota/cooldown
11. contexto grande
12. truncamento
13. QA veto
14. Security veto
15. Reviewer veto
16. autocorreção
17. repetição sem progresso
18. persistência
19. recuperação após restart
20. memória
21. pesquisa
22. multimídia
23. projeto persistente
24. isolamento
25. secret sanitization
26. path traversal
27. processo órfão
28. regressão
29. stress
30. missão longa

Critério:
teste precisa provar comportamento, não apenas retornar código 0.
