# Pacote integrado

- 25 agentes existentes do workspace
- 140 SKILL.md utilizáveis (4 Skills fornecidas + 136 Skills do Ruflo + adaptive-execution)
- Ruflo runtime via `npx -y ruflo@latest` no MCP
- biblioteca Ruflo espelhada em `tools/ruflo/.agents`
- Playwright MCP
- 9Router local como backend padrão
- `imperion-dev` como alias de sessão
- roteamento adaptativo por tarefa documentado no CLAUDE.md
- proteções para FiveM/FXServer/VPS preservadas

## Importante

O pacote não contém chaves de API. O xKiro não foi ativado dentro do 9Router porque a chave não foi fornecida neste pacote. Para ativá-lo, ele deve ser configurado no próprio 9Router de forma segura, fora do repositório.
